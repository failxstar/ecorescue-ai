# Reusable decision pattern: environmental incident priority

**Pattern tag:** `#policy`  
**Required hackathon tag:** `#strands-decider-2b`

## Typed question

```json
{
  "priority": {
    "type": "choice",
    "instructions": "Which response priority best fits this environmental incident report?",
    "criteria": {
      "emergency": "Immediate threat to human life, active fire, hazardous chemical spill, or severe immediate danger",
      "urgent": "Significant ongoing environmental harm that needs prompt action, but no clearly immediate threat to life",
      "routine": "Low-immediacy issue suitable for normal reporting, monitoring, or scheduled cleanup"
    }
  }
}
```

## How to reuse it

1. Pass the incident report as `state` and the typed question as `questions` to `POST /v1/decide`.
2. Read `answers.priority.choice` and `answers.priority.confidence`.
3. Apply deterministic thresholds in your own application. This demo flags confidence below `0.60` for human review.
4. Pass the chosen category to your generative model for explanation and next steps.
5. Keep a human in the loop. This demo does not dispatch emergency services and must not be treated as a substitute for official incident response.

The choice is the decision model's output; the downstream response text is generated by Amazon Bedrock through Strands Agents.
